## Nội dung chính

- Trong Excel 365: Data, Get Data, From Database, From SQL Server Database, rồi nhập tên máy chủ và database.
- Có thể dán câu lệnh SQL vào mục Advanced options, hoặc chọn thẳng bảng, view có sẵn.
- Bấm Refresh để lấy số mới, không phải xuất lại file.
- Nên trỏ Power Query vào một view (bài 4.5) thay cho câu lệnh dài, để logic nằm một chỗ trong database.

## Liên hệ Excel

Đây là cầu nối giữa hai bên: dữ liệu vẫn nằm trong SQL Server, Excel chỉ đọc ra để trình bày, vẽ biểu đồ, làm PivotTable.

## Tình huống ví dụ

Phòng nhân sự muốn file báo cáo Excel hằng tháng tự cập nhật số liệu mà không cần ai xuất dữ liệu.
