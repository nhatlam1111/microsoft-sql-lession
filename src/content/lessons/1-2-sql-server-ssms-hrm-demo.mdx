## Từ SSMS đến danh mục phòng ban

### Từ mở workbook đến kết nối máy chủ

Với Excel, bạn mở một **workbook** rồi chọn **sheet** cần xem. Workbook có thể ở máy bạn hoặc được dùng chung trên OneDrive/SharePoint. Với database khóa học, dữ liệu ở **máy chủ**, tức hệ thống cung cấp dữ liệu qua mạng; bạn dùng công cụ kết nối tới đó, thay vì mở trực tiếp file dữ liệu.

Nhắc lại bài 1.1: **database** là tập dữ liệu có cấu trúc; **SQL Server** là phần mềm quản lý database. **SSMS** (SQL Server Management Studio) là công cụ cài trên máy bạn để kết nối, tìm bảng, gửi câu lệnh và xem kết quả. Đóng SSMS không làm mất dữ liệu trên máy chủ.

Khóa học dùng **Azure SQL Database**, dịch vụ Microsoft quản lý trên nền bộ máy dữ liệu SQL Server. Những câu truy vấn T-SQL trong khóa học cũng dùng được với SQL Server; phần cài đặt và quản trị hai môi trường có khác nhau. Database chung đã có sẵn, nên dùng nguồn này thì không cần tự cài SQL Server. **HRM_Demo** là tên bộ dữ liệu nhân sự giả lập gồm bảy bảng; trên máy chủ khóa học, nó nằm trong database `free-sql-db-8797714`.

Đường đi tới bảng phòng ban là **máy chủ → database → bảng**:

- Máy chủ: `sql-lession.database.windows.net` — địa chỉ để SSMS kết nối.
- Database: `free-sql-db-8797714` — tương tự workbook chứa nhiều sheet.
- Bảng: `dbo.PhongBan` — tương tự sheet danh mục phòng ban. `dbo` là **schema**, một nhóm chứa các bảng; bảy bảng mẫu đều nằm trong nhóm này.

Để đi được đường đó, bạn cần bốn thông tin: **tên máy chủ**, **cách đăng nhập**, **tài khoản và mật khẩu**, **tên database**. Khóa học dùng **SQL Server Authentication**, tức tên đăng nhập và mật khẩu riêng được cấp; không lấy tài khoản Windows điền thay.

### Chọn nơi thực hành trước khi kết nối

**Thực hành trên web:** từ bài 1.6, bấm **Làm bài** để viết SQL trên trình duyệt, không cần Windows hay SSMS. **Mã truy cập** nhận từ người phụ trách hoặc người đã gửi bạn khóa học, khác tài khoản SSMS. Chưa có mã thì dùng bản riêng theo hướng dẫn dưới đây; bản riêng không có chấm tự động.

Nếu chỉ dùng web, ở bài 1.2 bạn cần phân biệt công cụ, hiểu đường **máy chủ → database → bảng** và chọn nơi thực hành. Bạn đọc các hình kết nối để nhận biết, chưa cần tự kết nối SSMS; việc viết và chạy SQL trên web bắt đầu từ bài 1.6.

Trên trang bài tập, **Chạy (F5)** hiện kết quả; **Nộp bài** còn đối chiếu yêu cầu. Trang nhận mỗi lần một câu lệnh, luôn **hoàn tác** thay đổi sau khi chạy. Cơ chế này chỉ có trên trang bài tập; trong SSMS, mặc định câu sửa thành công là ghi hẳn ngay, không có Ctrl+Z. Trên database dùng chung, ở Level 1 chỉ chạy các câu đọc có trong bài; cách hoàn tác học ở bài 5.4.

**Thực hành bằng SSMS:** công cụ này chỉ chạy trên Windows. Cài theo [hướng dẫn Microsoft](https://learn.microsoft.com/en-us/ssms/install/install), hoặc nhờ IT cài. Với nguồn dùng chung, nếu mạng chặn kết nối, gửi IT: “Máy em có được kết nối tới `sql-lession.database.windows.net` qua cổng `1433` không?”; cổng là đường kết nối mạng cần được cho phép. Thời lượng bài không tính thời gian cài phần mềm.

Khi dùng SSMS, chọn thông tin theo nơi đặt dữ liệu; đừng lấy tên database của môi trường này điền cho môi trường kia:

| Nơi thực hành | Server Name | Database | Authentication |
|---|---|---|---|
| Nguồn khóa học dùng chung | `sql-lession.database.windows.net` | `free-sql-db-8797714` | SQL Server Authentication; tài khoản được cấp |
| Bản SQL Server riêng | `localhost` hoặc `localhost\SQLEXPRESS` theo lúc cài | `HRM_Demo`, do bạn tạo | Windows Authentication |

**Bản riêng trên máy — tùy chọn:** bỏ qua nếu đã dùng web hoặc có tài khoản database khóa học. Muốn có dữ liệu riêng để thử:

1. Cài [SQL Server Express hoặc Developer](https://www.microsoft.com/en-us/sql-server/sql-server-downloads) phiên bản 2019 trở lên và SSMS. Hai bản đều miễn phí; Developer chỉ dành cho học, phát triển và thử nghiệm, không dùng cho hệ thống chạy thật.
2. Kết nối tới `localhost` nếu chọn **Default instance** (bản SQL Server không đặt tên riêng), hoặc `localhost\SQLEXPRESS` nếu Express giữ tên mặc định; chọn **Windows Authentication**. Trên máy riêng, nếu dùng chứng chỉ tự ký thì chọn **Encrypt: Mandatory** và **Trust Server Certificate**; không dùng cách bỏ kiểm chứng chỉ này cho máy chủ khóa học.
3. Trong **Object Explorer**, khung cây bên trái SSMS, bấm chuột phải **Databases → New Database…**, tạo database `HRM_Demo`.
4. Tải [HRM_Demo.sql](/microsoft-sql-lession/HRM_Demo.sql), mở bằng SSMS, chọn database riêng vừa tạo rồi bấm **Execute**. Kết quả báo `HRM_Demo đã sẵn sàng`; bấm chuột phải **Tables → Refresh** để thấy bảy bảng.

Script chỉ dùng trên database riêng: nó **xóa và tạo lại bảy bảng mẫu**, làm mất thay đổi bạn đã thực hiện trên các bảng đó. Nếu gặp bảng trùng tên không do script tạo hoặc bảng khác trỏ vào bảng mẫu, script dừng lại. Không chạy script trên database khóa học dùng chung.

### Kết nối và tìm bảng phòng ban

Hướng dẫn dưới dùng thông tin của database khóa học; nếu đã tạo bản riêng, thay thông tin kết nối bằng dòng tương ứng trong bảng trên. Mở SSMS; nếu hộp **Connect to Server** chưa hiện, chọn **Connect → Database Engine** trong Object Explorer bên trái. Các ô dưới minh họa nguồn dùng chung; bản riêng giữ thiết lập đăng nhập và chứng chỉ ở bước cài đặt trên. Với hộp kết nối kiểu mới, điền:

- **Server Name**: `sql-lession.database.windows.net`.
- **Authentication**: SQL Server Authentication.
- **User Name** và **Password**: tài khoản và mật khẩu được cấp.
- **Database Name**: `free-sql-db-8797714`.
- **Encrypt**: chọn **Strict** (tên đầy đủ có thể kèm SQL Server 2022 và Azure SQL).
- **Trust Server Certificate**: không bật; với Strict, ô này có thể bị vô hiệu hóa vì kết nối kiểm chứng chỉ máy chủ.

<Ssms view="connect" caption="Hộp kết nối kiểu mới. Ô Database Name có viền xanh: phải chỉ rõ database khóa học." />

Nếu dùng hộp kiểu cũ, **Login** thay cho User Name; bấm **Options >> → Connection Properties**, điền `free-sql-db-8797714` vào **Connect to database**. Thiết lập mã hóa và tên trường đối chiếu theo [hướng dẫn kết nối SSMS của Microsoft](https://learn.microsoft.com/sql/ssms/quickstarts/ssms-connect-query-sql-server).

Bấm **Connect**. Database có thể đang tự tạm dừng; nếu lần đầu chưa vào được, xem lỗi `40613` ở mục Hay nhầm ở đâu. Nếu xuất hiện **New Firewall Rule** yêu cầu đăng nhập Azure, bấm **Cancel** và nhờ người phụ trách xử lý.

Trong **Object Explorer**, mở **Databases → `free-sql-db-8797714` → Tables → `dbo.PhongBan` → Columns**. Giống xem tên cột trong sheet, bạn sẽ thấy bảng này có hai cột `MaPB` (mã phòng ban) và `TenPB` (tên phòng ban).

<Ssms view="explorer" table="PhongBan" mark={['MaPB', 'TenPB']} caption="Hai cột của dbo.PhongBan được đánh dấu. Chữ trong ngoặc mô tả khóa, kiểu dữ liệu và khả năng nhận NULL; bài 1.3 và 1.4 giải thích kỹ hơn." />

**Columns** cho biết cấu trúc, chưa phải các dòng dữ liệu. Để đọc danh mục, bạn gửi một câu lệnh như phần dưới. Tránh **Edit Top 200 Rows**: đó là lưới sửa dữ liệu dùng chung, không phải chế độ xem an toàn.

### Câu lệnh cho tình huống

Nếu chỉ dùng web, bạn đọc câu và kết quả để hiểu việc công cụ thực hiện; tự chạy ở phần thực hành từ bài 1.6. Nếu dùng SSMS, làm tiếp:

Bấm **New Query**. Ô chọn database bên cạnh nút **Execute** phải là `free-sql-db-8797714` (bản riêng là `HRM_Demo`); kết nối đúng máy chủ nhưng chọn nhầm database vẫn không tìm thấy bảng cần xem.

<Ssms view="toolbar" caption="Kiểm ô chọn database có viền xanh trước khi chạy câu lệnh." />

Gõ câu dưới đây, bấm **F5** hoặc **Execute** để lấy các dòng trong bảng `PhongBan`. Ở bài này chỉ cần kết nối đúng database và đọc danh mục; cú pháp `SELECT` học ở bài 1.6.

<Sql code={`SELECT * FROM PhongBan;`} />

<Result columns={['MaPB', 'TenPB']} rows={[
  ['BGD', 'Ban Giám đốc'],
  ['IT', 'IT'],
  ['KD', 'Kinh doanh'],
  ['KT', 'Kế toán'],
  ['NS', 'Nhân sự'],
  ['VH', 'Vận hành'],
]} />

Bạn có thể trả lời chị Hạnh: danh mục đang lưu sáu phòng, gồm `Ban Giám đốc`, `IT`, `Kinh doanh`, `Kế toán`, `Nhân sự`, `Vận hành`. Bảng `PhongBan` không có cột trạng thái hay ngày hiệu lực; muốn chắc phòng nào còn hoạt động trước buổi họp thì xác nhận với người quản lý danh mục.

Câu này không có `ORDER BY`, nên thứ tự dòng trên máy bạn có thể khác hình. Nếu chép kết quả sang Excel, file đó chỉ phản ánh dữ liệu lúc lấy, không tự cập nhật theo database.

Học xong, bấm chuột phải máy chủ trong Object Explorer → **Disconnect**, rồi đóng các cửa sổ truy vấn hoặc đóng SSMS để ngắt hết kết nối. Kết nối còn mở có thể giữ database thức và tiêu hao hạn mức miễn phí chung. Quyền truy cập học ở bài 6.1; môi trường làm việc học ở bài 6.2.

## Hay nhầm ở đâu

<Mistakes>

1. **Bỏ trống Database Name hoặc chọn nhầm database khi chạy.** Bạn có thể gặp lỗi đăng nhập `18456` dù mật khẩu đúng, hoặc vào được nhưng không tìm thấy `PhongBan`. Kiểm tên database cùng thông tin đăng nhập trước khi xin mật khẩu mới.
2. **Gõ thiếu tên máy chủ.** Phải dùng đủ `sql-lession.database.windows.net`. Nếu tên đúng mà vẫn không tới được máy chủ, hoặc lỗi nhắc địa chỉ IP, gửi nguyên văn lỗi cho người phụ trách để kiểm mạng và tường lửa.
3. **Gặp 40613 rồi nghĩ sai tài khoản.** Lỗi này thường xuất hiện khi database đang thức dậy, nhưng cũng có thể do dịch vụ tạm thời không sẵn sàng. Chờ khoảng một phút rồi thử lại; nếu vẫn lỗi sau vài lần, gửi nguyên văn lỗi cho người phụ trách. Nếu thông báo nhắc hết hạn mức miễn phí, chờ khởi động không giải quyết được.

</Mistakes>

<details>
<summary>SQL Server, database và SSMS giữ vai trò gì?</summary>

Database là tập dữ liệu có cấu trúc; SQL Server là phần mềm quản lý database; SSMS là công cụ kết nối và gửi câu lệnh. Đóng SSMS không xóa dữ liệu trên máy chủ.

</details>

<details>
<summary>Hai lối thực hành cần chuẩn bị gì?</summary>

Web cần mã truy cập từ người phụ trách, bắt đầu viết SQL ở bài 1.6. SSMS cần Windows, tên máy chủ, cách đăng nhập, tài khoản và mật khẩu nếu dùng SQL Server Authentication, cùng tên database. Chưa có mã thì tạo bản riêng `HRM_Demo`; bản riêng không có chấm tự động.

</details>

<details>
<summary>Tìm thấy <code>dbo.PhongBan</code> trong Object Explorer rồi thì xem các dòng ở đâu?</summary>

Mở New Query, kiểm đúng database, chạy `SELECT * FROM PhongBan;` bằng F5 hoặc Execute. Mục Columns chỉ mô tả cột, không hiện các dòng phòng ban.

</details>

<details>
<summary>Kết quả có sáu dòng thì chắc cả sáu phòng còn hoạt động?</summary>

Chưa chắc. Đó là sáu phòng trong danh mục đang lưu; bảng không có trạng thái hay ngày hiệu lực. Cần xác nhận với người quản lý danh mục nếu yêu cầu là các phòng còn hoạt động.

</details>

<details>
<summary>SSMS có tự hoàn tác như trang bài tập không?</summary>

Không. Việc luôn hoàn tác chỉ có trên trang bài tập. Trong SSMS, trên database khóa học dùng chung, ở giai đoạn này bạn chỉ chạy các câu chỉ đọc trong bài; không dùng Edit Top 200 Rows. Học xong ngắt hết kết nối.

</details>
