## Nội dung chính

- SQL Server là phần mềm giữ database. Một máy chủ SQL Server chứa được nhiều database, mỗi database có nhiều bảng.
- SSMS (SQL Server Management Studio) là công cụ để kết nối tới máy chủ, xem bảng và chạy câu lệnh. Khi kết nối cần tên máy chủ, cách đăng nhập và database muốn mở.
- Cửa sổ Object Explorer bên trái liệt kê database, bảng và cột, giống dãy tên sheet ở cuối một file Excel.
- Tạo database `HRM_Demo` rồi chạy script tải ở trang Giới thiệu là có đủ 7 bảng nhân sự dùng cho cả khóa.
- Mở cửa sổ New Query và chọn đúng database trên thanh công cụ trước khi chạy lệnh.

## Liên hệ Excel

Mở một file Excel là mở cả dữ liệu lẫn công thức ngay trên máy của mình. Với SQL Server, dữ liệu nằm trên máy chủ; SSMS chỉ là cửa sổ để nhìn vào và ra lệnh, nên nhiều người cùng làm việc trên một bản dữ liệu duy nhất.

## Tình huống ví dụ

Bạn vừa được cấp tài khoản vào database nhân sự và cần mở được bảng nhân viên trước buổi họp chiều nay.
