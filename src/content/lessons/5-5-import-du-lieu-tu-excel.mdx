## Nội dung chính

- SSMS có Import Flat File và Import and Export Wizard để đưa dữ liệu từ file vào database.
- Nên import vào một bảng tạm (staging) trước, chưa đụng tới bảng thật.
- Soát dữ liệu trên bảng tạm: mã trùng, mã phòng ban không có trong danh mục, ngày tháng sai định dạng, ô bắt buộc bị trống.
- Bảng tạm sạch rồi mới `INSERT … SELECT` sang bảng thật, gói trong một transaction.

## Liên hệ Excel

Giống file mẫu import: cột nào bắt buộc, định dạng ra sao. Bảng tạm là nơi soát file đó bằng câu lệnh thay vì soát bằng mắt.

## Tình huống ví dụ

Một chi nhánh gửi file Excel 30 nhân viên mới, cần đưa vào hệ thống trước kỳ lương.
