## Từ phần mềm Excel đến hệ quản lý SQL Server

Bạn dùng Excel để xử lý workbook. Database cần phần mềm quản lý; người dùng gửi yêu cầu qua ứng dụng, không mở trực tiếp tệp dữ liệu trên máy chủ.

**Microsoft SQL Server** là hệ quản lý database quan hệ của Microsoft. Nó lưu, đọc, cập nhật và bảo vệ dữ liệu, có thể quản lý nhiều database. Phần mềm này có thể chạy trên Windows hoặc Linux, ở máy của bạn hoặc máy chủ cung cấp dịch vụ qua mạng.

### Bốn tên và cách chúng làm việc cùng nhau

**SQL** là ngôn ngữ yêu cầu đọc hoặc thay đổi dữ liệu. **T-SQL** (Transact-SQL) là cách triển khai SQL của Microsoft, có cú pháp và tính năng mở rộng. Khóa học dùng T-SQL.

**SSMS** (SQL Server Management Studio) là công cụ trên Windows để kết nối, xem cấu trúc, gửi câu lệnh và đọc kết quả. Đóng SSMS không xóa database trên máy chủ.

| Tên | Vai trò |
|---|---|
| Database | Dữ liệu được lưu và cấu trúc của dữ liệu |
| SQL Server | Phần mềm quản lý, xử lý yêu cầu trên database |
| SQL/T-SQL | Ngôn ngữ diễn đạt yêu cầu |
| SSMS | Công cụ để bạn kết nối và gửi yêu cầu |

Ứng dụng nhân sự cũng có thể gửi yêu cầu tới SQL Server mà người dùng không mở SSMS.

### Ưu điểm đi cùng điều kiện sử dụng

SQL Server thuận tiện khi lấy thông tin qua nhiều bảng, như hồ sơ kèm tên phòng. **Ràng buộc** là luật được khai báo, như mã không được trùng; bài 1.4 giải thích giới hạn của luật.

**Phân quyền** giới hạn phần dữ liệu từng tài khoản được đọc/sửa. **Giao dịch (transaction)** giúp nhóm thao tác cùng hoàn tất hoặc cùng hoàn tác khi được lập trình và xử lý đúng. Các khả năng này cần cấu hình và cách dùng phù hợp.

SSMS hỗ trợ viết truy vấn và quản trị. Sao lưu/khôi phục giúp xử lý sự cố khi có cấu hình và bản sao lưu dùng được, không bảo đảm phục hồi được mọi lỗi.

### Giới hạn, edition và nơi thực hành

**Edition** là bản sản phẩm với tính năng và tài nguyên khác nhau. Không lấy giới hạn bản miễn phí làm giới hạn chung của SQL Server. Các nhóm trong SQL Server 2025:

| Nhóm edition | Điều cần biết |
|---|---|
| Express | Miễn phí, giới hạn tài nguyên và kích thước database; phù hợp nhu cầu nhỏ |
| Standard, Enterprise | Bản thương mại, khác nhau về tính năng, giới hạn và chi phí |
| Standard Developer, Enterprise Developer | Dùng phát triển/kiểm thử, không được cấp phép làm hệ thống vận hành thật |
| Evaluation | Bản đánh giá có thời hạn |

Hệ thống cần người thiết kế, quản lý quyền và theo dõi hiệu năng. Tăng dữ liệu/người dùng có thể cần thêm tài nguyên hoặc tối ưu truy vấn. SQL Server không tự biết dữ liệu đúng nghiệp vụ hay tự đồng bộ file Excel.

Khóa học dùng **Azure SQL Database**, dịch vụ Microsoft quản lý trên Azure, dùng chung nền tảng xử lý với SQL Server. Cú pháp cốt lõi dùng được trên cả hai; tính năng quản trị và giới hạn có thể khác. Lối học trên web không cần tự cài SQL Server.

Nguồn: [Microsoft — SQL Server](https://learn.microsoft.com/en-us/sql/sql-server/what-is-sql-server), [edition SQL Server 2025](https://learn.microsoft.com/en-us/sql/sql-server/editions-and-components-of-sql-server-2025), [SSMS](https://learn.microsoft.com/en-us/ssms/sql-server-management-studio-ssms).

Ở bài này chỉ cần phân biệt các tên và biết khả năng đi cùng điều kiện. Bạn bắt đầu viết câu lệnh ở bài 2.1; [chọn nơi thực hành tại trang Giới thiệu](/microsoft-sql-lession/gioi-thieu/#chon-noi-thuc-hanh). Phân quyền học ở bài 6.1, giao dịch ở bài 5.5, sao lưu ở bài 6.3.

## Hay nhầm ở đâu

<Mistakes>

1. **Cài SSMS rồi nghĩ đã có SQL Server.** SSMS chỉ là công cụ kết nối; bạn còn cần một hệ thống database để gửi yêu cầu tới.
2. **Thấy cùng chữ SQL thì chép mọi cú pháp giữa các sản phẩm.** Phần mở rộng có thể khác, nên câu chạy ở sản phẩm khác chưa chắc chạy trên SQL Server.

</Mistakes>

## Ứng dụng

<Apply>

- **Báo lỗi đúng thành phần:** phân biệt công cụ SSMS, kết nối và hệ quản lý để mô tả lỗi rõ hơn cho người phụ trách.
- **Chọn đúng nơi thực hành:** dùng web được cấp mã hoặc SSMS theo hướng dẫn, không cài thêm hệ quản lý khi chưa cần bản riêng.

</Apply>

**Tự kiểm tra trước khi bấm "Đã học xong":**

<details>
<summary>SSMS, SQL Server và database giữ ba vai trò nào?</summary>

SSMS kết nối/gửi yêu cầu; SQL Server quản lý; database là dữ liệu và cấu trúc được quản lý.

</details>

<details>
<summary>SQL và T-SQL có quan hệ thế nào?</summary>

SQL là ngôn ngữ yêu cầu dữ liệu. T-SQL là cách triển khai SQL của Microsoft, có thêm cú pháp và tính năng riêng.

</details>

<details>
<summary>Nêu một ưu điểm của SQL Server cùng điều kiện để ưu điểm đó có tác dụng.</summary>

Ví dụ: phân quyền giới hạn người được sửa dữ liệu, nhưng phải cấu hình quyền phù hợp. Sao lưu hỗ trợ khôi phục khi có bản sao lưu dùng được.

</details>

<details>
<summary>Giới hạn của Express có áp dụng cho mọi edition và Azure SQL Database không?</summary>

Không. Giới hạn phụ thuộc edition, phiên bản hoặc mức dịch vụ. Azure SQL Database là dịch vụ được quản lý, không đồng nhất mọi tính năng với SQL Server tự cài.

</details>
